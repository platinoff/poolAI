pub fn get_global_manager() -> Arc<VmManager> ⓘ
Expand description

Get global VM manager instance.

This function returns a singleton instance of VmManager that can be used throughout the application. The instance is created on first access and reused for subsequent calls.

§Examples

use poolai::vm::get_global_manager;
use uuid::Uuid;

let manager = get_global_manager();

// List all VM instances
let instances = manager.list_instances().await;
for instance in instances {
    println!("VM: {} ({:?})", instance.name, instance.status);
}
