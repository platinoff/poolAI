TLS policy and rustls server configuration (PH-S08 / FM-044).

  • Policy: TlsConfig from HttpsConfig (min/max TLS, HSTS).
  • Runtime (feature = "https"): PEM load, TLS 1.3-first rustls [ServerConfig], hot reload via RustlsConfig::reload_from_config.
