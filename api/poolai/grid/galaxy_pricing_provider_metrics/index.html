Galaxy pricing provider catalog metrics (PH-S172, PH-S173, §4.2.5).

Counters when [GalaxyPricingProviderCatalog::matching_entries] resolves allow-list hits and when live provider HTTP fetch fails in [fetch_live_provider_quotes].
