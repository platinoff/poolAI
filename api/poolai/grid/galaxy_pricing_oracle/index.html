Module galaxy_pricing_oracle 

Source
Expand description

Galaxy Grid pricing oracle stub (PH-S68): unit keys, floor(market_min×0.9) quote, cache TTL/SWR from POOLAI_GALAXY_PRICE_* env; L2 force-fallback ops wire (PH-S81); L1 stale-served metric (PH-S83); L1 fresh-served metric (PH-S91); L1 cache TTL metadata (PH-S89); POOLAI_GALAXY_PRICING_PROVIDERS allow-list catalog stub (PH-S92). See docs/concept/POOLAI_GALAXY_GRID.md §4.2.

Oracle determines gross quote in micro-USD; settlement uses galaxy_fee_split.
