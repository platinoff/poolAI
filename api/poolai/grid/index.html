Grid protocol wire types (FM-009 / Horizon S36).

JSON GridEnvelope v1 unifies logical messages (Job, Result, MemoryShard, PeerStatus) for transport over HTTP/WebSocket or future QUIC. See docs/development/GRID_PROTOCOL_CONCEPT_2026-04-06.md.
