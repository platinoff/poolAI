Galaxy Grid fee split (PH-S58): primary 0.1% (dev) + secondary 1–5% (admin), remainder to worker/operator pool. Integer math on gross payment in atomic units (e.g. SOL lamports). See docs/concept/POOLAI_GALAXY_GRID.md.
