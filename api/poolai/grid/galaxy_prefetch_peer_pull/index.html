Peer HTTP seed-pull prefetch wire (PH-S537, Galaxy §5.5).

When POOLAI_GALAXY_PREFETCH_PEER_HTTP_URL is set, fetch seed inventory over HTTP instead of the in-process coordinator snapshot stub.

Constants§

ENV_PREFETCH_PEER_HTTP_TIMEOUT_MS
Env: HTTP timeout ms for peer seed pull (default 2000).
ENV_PREFETCH_PEER_HTTP_URL
Env: peer seed-inventory HTTP URL for live pull (PH-S537).
