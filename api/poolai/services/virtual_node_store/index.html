Module virtual_node_store

File-backed store for virtual-node coordinator state (FM-016+).

Set POOLAI_VIRTUAL_NODE_DATA_DIR (e.g. data/virtual_nodes) to persist bindings and task queues across coordinator restarts. When unset, only in-memory state is used.
