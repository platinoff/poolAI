# PoolAI Docs Index (2026-04-04)

## 1. Концепція та бачення

- `concept/poolAI_concept_root.txt` — головна концепція PoolAI як **Distributed AI Mining Pool Management System** (історичний повний опис).
- `concept/poolAI_concept.txt`, `concept/poolAI_concept_workspace.txt` — деталізація майнінгу нового покоління, модулів, фаз розвитку.
- `concept/CONCEPT_UPDATE_2026-01-19.md` — оновлення концепції до v7 (RAID, Enterprise, Cloud, ML).

### Нові концепти Grid / Memory / Job (2026-03-17)

- `concept/POOLAI_GRID_NODE.md` — опис **PoolAI Node** як вузла грида:
  - ролі `miner / hub / hybrid`;
  - як 15 модулів складаються в єдиний Node Runtime;
  - як RAID/SmallWorld/Discovery утворюють Grid Layer.
- `concept/POOLAI_MEMORY_LAYER.md` — **Memory Layer / AGI‑памʼять**:
  - RAID + ML (Pruning/AutoML/Federated/Context Monitor) як памʼять;
  - поведінка “як торент” через seeds/shards;
  - звʼязок із Grid/Job‑рівнем.
