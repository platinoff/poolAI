# Cursor: порожні або обрізані відповіді в чаті

## Симптоми
- Пишете в чат, відповіді не з’являються (пусте місце під повідомленнями).
- **Відповіді обрізані / не закінчені** — кінець тексту як «…added», «…Command», повідомлення обривається.
- «Критичне вікно заповнене», контекст переповнений.

## Відомий баг (Cursor ~v2.2.44)
У деяких версіях чат/план показуються порожніми. Помилка в консолі:  
`Element already has context attribute: editor-instance`.

## Що зробити (по черзі)

1. **Перезавантажити вікно**  
   `Ctrl+Shift+P` → **Developer: Reload Window** → Enter.

2. **Новий чат**  
   Кнопка **New Chat** (або **New Agent**) у панелі чату. Задайте питання в новому чаті.

3. **Перезапустити Cursor**  
   Повністю закрити й знову відкрити Cursor.

4. **Зменшити контекст**  
   - Закрийте зайві вкладки (файли).  
   - Не додавайте надто багато файлів через `@` в один чат.  
   - Якщо використовуєте Agent — спробуйте звичайний Chat.  
   - **Якщо відповіді обрізані** — те саме: новий чат, менше @-файлів, reload.

5. **Перевірити консоль**  
   `Help` → **Toggle Developer Tools** → вкладка **Console**.  
   Якщо є червоні помилки — можна зберегти їх і надіслати в підтримку Cursor.

6. **Налаштування (вже застосовано)**  
   У `settings.json` увімкнено:
   - `cursor.general.enableAgent`: true  
   - `cursor.general.enableComposer`: true
