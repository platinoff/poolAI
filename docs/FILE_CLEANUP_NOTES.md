1. **Перезапустіть IDE** - це може оновити дерево файлів
2. **Перевірте через термінал**:
   ```powershell
   cd S:\rust\poolAI
   Get-ChildItem -Force | Where-Object { $_.Name -eq '-5' }
   ```
3. **Видаліть через git** (якщо файл в git):
   ```powershell
   git rm --cached "-5"
   git commit -m "Remove problematic -5 file"
   ```
4. **Видаліть вручну** через файловий менеджер Windows
